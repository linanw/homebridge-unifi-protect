# Plugin development

Follow the MatterDesk plugin specification in the sibling checkout at
`../matterdesk-unified/docs/PLUGIN_DEVELOPMENT.md`, or `docs/PLUGIN_DEVELOPMENT.md` in the linanw/MatterDesk repository when working independently.
Maintain this plugin in linanw's public GitHub fork and publish it publicly under the @linanw npm scope. Do not create upstream pull requests. Preserve existing project-specific build and test instructions.
